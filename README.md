# CarWise — Modern Digital Automotive Showroom 🚗⚡

CarWise is a modern, responsive digital showroom application designed to help car buyers explore vehicles, compare tradeoffs, chat with an AI automotive concierge, book doorstep test drives, and complete end-to-end simulated reservations.

![CarWise Preview](img/volvo-ex30.jpg)

---

## ✨ Features

- **Atmospheric Showcase Hero**: Interactive vehicle spotlights, quick lifestyle chips, and trust highlights.
- **Showroom Catalog & Filters**: Instant powertrain (*100% Electric*, *Hybrid*, *Petrol*), budget, and safety rating filters.
- **Vehicle Detail Studio**: High-res studio imagery, interactive color swatches with live ambient glow reflection, performance quadrant, and verified pros & tradeoffs balance sheet.
- **Head-to-Head Comparison**: Compare up to 3 cars with side-by-side specs, safety ratings, pricing, and direct action triggers.
- **Doorstep Test Drive Booking**: Schedule appointment windows with instant digital boarding pass generation.
- **Simulated Payment Gateway**: Safe 256-bit test checkout simulating Credit/Debit Cards (live card preview & Luhn validation), UPI QR laser scanner, NetBanking, and EMI plans.
- **AI Automotive Concierge**: Built-in conversational AI answering questions, comparing models, and suggesting suitable vehicles across the entire fleet.
- **User Activity Hub**: Track scheduled drives and orders with visual progress timelines.

4. Your website will be live at `https://<your-username>.github.io/<repo-name>/`!

## 💻 Running Locally

No build tools or compilers are required. Simply open with any static server:

```bash
# Using Python
python -m http.server 3000

# Or using Node.js npx serve
npx serve -l 3000
```

Open `http://localhost:3000` in your web browser.
